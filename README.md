# RK's Villa — Luxury 4-BHK Direct Booking Web Application
**Siolim, North Goa | Host Direct Booking Engine**

## 🌴 Overview
This repository contains the complete direct booking website for **RK's Villa** located in Siolim Marna Village, North Goa. Designed for maximum conversion, fast loading speeds, zero platform commissions (saving 15–20% vs Airbnb), and seamless mobile UX.

## 🔑 Key Features
1. **Primary Video Engine**: `hero-loop.mp4` silent background loop and `full-tour-opt.mp4` (CRF 23 optimized, `preload="none"`) virtual tour player to save Netlify bandwidth.
2. **YouTube Facade**: Click-to-load video facade on `index.html` for travel vlog feature (`gWLk2z4-lLo` by Explore With Gaurav), ensuring 0ms page-speed penalty on initial load.
3. **Hostex PMS Sync**: Embedded dual-month availability calendar (`calendar.js`) with an interactive Direct Booking Price & Savings Calculator.
4. **3-Level Floor Breakdown**: Detailed room specifications on `villa.html` featuring the Top Floor Master Suite with a soaking bathtub.
5. **PDF Amenities & House Rules**: Air Fryer, Gas Burner, Oven, Toaster, Kettle, Mixer/Grinder, Karaoke Sound Box, and House Rules accordion.
6. **7 Curated Experiences**: Floating Pool Breakfast, Private Chef Seafood BBQ, Pergola Sundowners, Karaoke Night, Yacht Charter, In-Villa Massage, and Bonfire Movie Night with direct WhatsApp pre-filled action buttons.
7. **CSS Masonry Gallery**: High-res property photo grid on `gallery.html` (`2.png` to `11.png`).
8. **Location Guide**: Exact distances for transit (Manohar Airport 21.3km, Thivim 12.2km), beaches (Vagator 7.8km, Anjuna 8.9km), dining hotspots (Thalassa 3.8km, Hosa 2.1km), and GPS coordinates `15.6159° N, 73.7872° E`.

## 🚀 Deployment Instructions (Netlify)

1. **Upload / Connect Repository**: Connect this workspace directory to Netlify or drag-and-drop the directory into Netlify Web Console.
2. **Build Settings**:
   - **Publish directory**: `./` (Root directory)
   - **Build command**: Leave blank (Static site with pure HTML/CSS/JS)
3. **Domain Setup**: Point custom domain (e.g. `rksvilla.com` or `rksvilla.in`) to Netlify DNS.
4. **Web3Forms Key**: Optional — Replace `YOUR_WEB3FORMS_ACCESS_KEY` in `contact.html` with your free Web3Forms access key for direct email delivery.
